# Build with Componentry

<p className="doc-lead">A shared design language for the interfaces you make. Built with web components, ready for React, Vue, and Angular.</p>

Componentry keeps component behavior in a single Stencil implementation and generates framework wrappers around it. Shared theme tokens keep the look consistent across applications.

## Explore the components

Start with the [Button documentation](./components/button.mdx): try the interactive playground, compare variants, and copy an example for your framework.

## Run this repository

Use the pnpm version specified in the root `package.json`. From the repository root:

```bash
pnpm install --frozen-lockfile
pnpm build:packages
pnpm dev:docs
```

Build the packages before starting documentation so the local component imports are available.

## Choose your framework

| Framework | Component package | Example app |
| --- | --- | --- |
| React | `@componentry-ui/react` | `pnpm dev:react` |
| Vue | `@componentry-ui/vue` | `pnpm dev:vue` |
| Angular | `@componentry-ui/angular` | `pnpm dev:angular` |
| HTML | `@componentry-ui/stencil` | `pnpm dev:stencil` |

## Load a theme

Import the shared theme once in your application's entry point:

```ts
import '@componentry-ui/theme/styles/light.css';
import '@componentry-ui/theme/styles/dark.css';
```

Apply `c-theme-light` or `c-theme-dark` to your document's root element to select a theme. The documentation previews follow the theme toggle in the navigation bar.
