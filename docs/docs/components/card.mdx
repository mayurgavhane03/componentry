## Anatomy

A card is composed of a root `c-card` element plus composable sub-elements. `c-card-header` supports named slots for `title`, `description`, and `action`.

```
┌───────────────────────────────────────────────┐
│ c-card                                        │
│  ┌─────────────────────────────────────────┐  │
│  │ c-card-header                           │  │
│  │  [slot="title"]       [slot="action"]   │  │
│  │  [slot="description"]                   │  │
│  └─────────────────────────────────────────┘  │
│  ┌─────────────────────────────────────────┐  │
│  │ c-card-content                          │  │
│  │  (body content, forms, media, text)     │  │
│  └─────────────────────────────────────────┘  │
│  ┌─────────────────────────────────────────┐  │
│  │ c-card-footer                           │  │
│  │  (buttons, actions, metadata)           │  │
│  └─────────────────────────────────────────┘  │
└───────────────────────────────────────────────┘
```

| Component | Tag | Description |
|---|---|---|
| **Root Container** | `c-card` | The outer surface container with border, radius, and elevation |
| **Header** | `c-card-header` | Header region containing slots for title, description, and action |
| **Title** | `c-card-title` | Formatted title heading (placed in `slot="title"`) |
| **Description** | `c-card-description` | Subtitle or secondary caption (placed in `slot="description"`) |
| **Action** | `c-card-action` | Header action slot for badges or icon buttons (placed in `slot="action"`) |
| **Content** | `c-card-content` | The main body region of the card |
| **Footer** | `c-card-footer` | Bottom region for actions, buttons, and status indicators |

## Component API

### `<c-card>` Properties

| Property | Attribute | Description | Type | Default |
|---|---|---|---|---|
| `size` | `size` | Spacing density. `'sm'` uses compact padding. | `'default' \| 'sm'` | `'default'` |

### Slots

| Component | Slot Name | Description |
|---|---|---|
| `c-card` | *(default)* | Container children: header, content, footer |
| `c-card-header` | `title` | The primary title element (e.g. `<c-card-title slot="title">`) |
| `c-card-header` | `description` | Subtitle or secondary description (e.g. `<c-card-description slot="description">`) |
| `c-card-header` | `action` | Top-right header element, such as a badge or button |
| `c-card-content` | *(default)* | Body content of the card |
| `c-card-footer` | *(default)* | Bottom actions and footer content |

## Design Tokens

Custom CSS properties that control card appearance:

| CSS Variable | Description | Default |
|---|---|---|
| `--card-spacing` | Inner padding applied to card regions | `var(--c-spacing-large)` (or `var(--c-spacing-medium)` when `size="sm"`) |
| `--c-border-radius-large` | Corner radius of the card | `12px` |
| `--c-panel-background-color` | Background surface color | Light: `#ffffff`, Dark: `#18181b` |
| `--c-panel-border-color` | Border stroke color | `var(--c-color-neutral-200)` |
| `--c-panel-border-width` | Border stroke width | `1px` |
| `--c-shadow-small` | Box shadow elevation | `0 1px 3px rgba(0, 0, 0, 0.08)` |
