## Usage

Import the component for your framework and load the [shared theme](../intro.mdx#load-a-theme) once in your application. These examples assume your application resolves the Componentry packages.

<FrameworkTabs
  react={`import { CButton } from '@componentry-ui/react';
import '@componentry-ui/theme/styles/light.css';

export default function App() {
  return <CButton variant="primary">Create project</CButton>;
}`}
  vue={`<script setup>
import { CButton } from '@componentry-ui/vue';
import '@componentry-ui/theme/styles/light.css';
</script>

<template>
  <CButton variant="primary">Create project</CButton>
</template>`}
  angular={`import { Component } from '@angular/core';
import { CButton } from '@componentry-ui/angular';

@Component({
  selector: 'app-example',
  standalone: true,
  imports: [CButton],
  template: '<c-button variant="primary">Create project</c-button>',
})
export class ExampleComponent {}

// Load @componentry-ui/theme/styles/light.css
// once in your application's entry point.`}
  html={`<!-- In a bundler-based vanilla JavaScript application -->
<script type="module">
  import { defineCustomElementCButton } from
    '@componentry-ui/stencil/components';
  import '@componentry-ui/theme/styles/light.css';
  defineCustomElementCButton();
</script>

<c-button variant="primary">Create project</c-button>`}
/>

<div className="doc-note"><strong>A useful default.</strong> Buttons use <code>type="button"</code>, so they won't submit a form accidentally. Choose an explicit submit or reset type when you need that behavior.</div>

## Variants

Choose a style that matches the action's importance. Use **primary** for the main action, **default** or **neutral** for supporting actions, and **danger** for destructive actions. Semantic variants should always have a clear text label.

<ButtonVariants />

## Sizes

Keep the size consistent within a group. Use small buttons in dense interfaces, medium for everyday actions, and large when the action needs more space.

<Example react={`<CButton variant="primary" size="small">Small</CButton>

<c-button variant="primary" size="large">Large</c-button>`}>

## Outline and shape

Use `outline` for a lighter visual emphasis and `pill` for rounded ends. The `caret` property adds a visual indicator; it does not open a menu by itself.

<Example react={`<CButton variant="primary" outline>View details</CButton>
<CButton variant="primary" pill>Follow along</CButton>
<CButton caret>More actions</CButton>`}
html={`<c-button variant="primary" outline>View details</c-button>
<c-button variant="primary" pill>Follow along</c-button>
<c-button caret>More actions</c-button>`}>
  <CButton variant="primary" outline>View details</CButton>
  <CButton variant="primary" pill>Follow along</CButton>
  <CButton caret>More actions</CButton>
</Example>

## Icons and slots

Use the native `prefix` and `suffix` slots for presentational content before and after the label. In Vue, use the element's `slot` attribute as shown here.

<Example react={`<CButton variant="primary">
  <span slot="prefix" aria-hidden="true">＋</span>
  Add project
</CButton>
<CButton>
  Continue
  <span slot="suffix" aria-hidden="true">→</span>
</CButton>`}
html={`<c-button variant="primary">
  <span slot="prefix" aria-hidden="true">＋</span>
  Add project
</c-button>
<c-button>
  Continue
  <span slot="suffix" aria-hidden="true">→</span>
</c-button>`}>
  <CButton variant="primary"><span slot="prefix" aria-hidden="true">＋</span>Add project</CButton>
  <CButton>Continue<span slot="suffix" aria-hidden="true">→</span></CButton>

The `circle` property makes an icon button circular. Keep a visually hidden text label inside the default slot so the inner button has an accessible name.

```html
<c-button circle>
  <span aria-hidden="true">＋</span>
  <span class="visually-hidden">Add project</span>
</c-button>
```

```css
.visually-hidden {
  position: absolute;
  width: 1px;
  height: 1px;
  padding: 0;
  margin: -1px;
  overflow: hidden;
  clip-path: inset(50%);
  white-space: nowrap;
  border: 0;
}
```

## Loading and disabled

Show progress with `loading` and prevent another action with `disabled`. Try the example: saving is simulated for a little over a second.

<SaveExample />

<FrameworkTabs
  react={`<CButton variant="primary" loading={isSaving} disabled={isSaving}>
  Save changes
</CButton>
<span role="status">{isSaving ? 'Saving changes…' : ''}</span>`}
  vue={`<CButton variant="primary" :loading="isSaving" :disabled="isSaving">
  Save changes
</CButton>
<span role="status">{{ isSaving ? 'Saving changes…' : '' }}</span>`}
  angular={`<c-button variant="primary" [loading]="isSaving" [disabled]="isSaving">
  Save changes
</c-button>
<span role="status">{{ isSaving ? 'Saving changes…' : '' }}</span>`}
  html={`<c-button variant="primary" loading disabled>Save changes</c-button>
<span role="status">Saving changes…</span>
<!-- Remove both attributes when the operation finishes. -->`}
/>

`loading` is a visual state and skips the component's internal form handling. It does not set native `disabled`, announce progress, or reliably block your own click handlers. Pair it with `disabled` and a status message while an operation is running.

<Example react={`<CButton disabled>Unavailable</CButton>
<CButton variant="primary" disabled>Create project</CButton>`}
html={`<c-button disabled>Unavailable</c-button>
<c-button variant="primary" disabled>Create project</c-button>`}>
  <CButton disabled>Unavailable</CButton>
  <CButton variant="primary" disabled>Create project</CButton>
</Example>

## Links and forms

### Navigate with a link

Set `href` to render an anchor. The `target`, `rel`, and `download` properties apply only when `href` is present.

<Example react={`<CButton href="/docs/intro">
  Read the introduction
  <span slot="suffix" aria-hidden="true">↗</span>
</CButton>`}
html={`<c-button href="/docs/intro">
  Read the introduction
  <span slot="suffix" aria-hidden="true">↗</span>
</c-button>`}>
  <CButton href="/docs/intro">Read the introduction<span slot="suffix" aria-hidden="true">↗</span></CButton>
</Example>

### Submit or reset a form

Use `type="submit"` to submit the nearest ancestor form and `type="reset"` to restore its controls. A submit button's `name` and `value` are included in the form data.

```html
<form action="/projects" method="post">
  <label>
    Project name
    <input name="projectName" required />
  </label>
  <c-button type="submit" name="action" value="create" variant="primary">
    Create project
  </c-button>
  <c-button type="reset">Reset</c-button>
</form>
```

The component finds the form with `closest('form')`. Place it inside the form; there is no `form` property for associating it with a distant form.

## Accessibility

- Use a concise action label such as “Save changes” or “Create project.”
- Keep visible focus indicators. Native buttons support activation with **Enter** and **Space**.
- Give icon buttons a text alternative inside their label slot. A tooltip alone is not a sufficient label.
- Disabled buttons leave the keyboard tab order. Explain why an action is unavailable in nearby text.
- Announce asynchronous results through a separate `role="status"` region.
- Link mode currently sets `role="button"` on an anchor. It retains anchor keyboard behavior; Space activation is not implemented. Use a normal link when you need standard link semantics.

## API reference

### Properties

| Property | Type | Default | Purpose |
| --- | --- | --- | --- |
| `variant` | `default · primary · success · neutral · warning · danger · text` | `default` | Visual treatment. |
| `size` | `small · medium · large` | `medium` | Button size. |
| `outline` | `boolean` | `false` | Outlined treatment. |
| `pill` | `boolean` | `false` | Fully rounded ends. |
| `circle` | `boolean` | `false` | Circular icon button. |
| `caret` | `boolean` | `false` | Decorative dropdown indicator. |
| `disabled` | `boolean` | `false` | Disable interaction and remove from tab order. |
| `loading` | `boolean` | `false` | Show a spinner. Pair with disabled. |
| `type` | `button · submit · reset` | `button` | Form action. |
| `name` | `string` | `''` | Submitter name. |
| `value` | `string` | `''` | Submitter value. |
| `href` | `string` | `''` | Anchor destination. |
| `target` | `_blank · _parent · _self · _top` | — | Link browsing context. |
| `rel` | `string` | `noreferrer noopener` | Link relationship. |
| `download` | `string` | — | Suggested download filename. |
| `tooltip` | `string` | `''` | Native title text. |

For boolean attributes in HTML, add the attribute to enable the option and remove it to disable the option.

### Events

| Event | React handler | Behavior |
| --- | --- | --- |
| `click` | `onClick` | Native click event. |
| `cFocus` | `onCFocus` | Inner control gains focus; bubbles and crosses shadow boundaries. |
| `cBlur` | `onCBlur` | Inner control loses focus; bubbles and crosses shadow boundaries. |
| `cInvalid` | `onCInvalid` | Declared, but not emitted by the current implementation. |

### Methods

All methods return promises. Call them on a reference to the `c-button` element.

| Method | Returns | Purpose |
| --- | --- | --- |
| `triggerClick()` | `Promise<void>` | Click the inner control. |
| `setFocus(options?)` | `Promise<void>` | Focus the control; accepts native `FocusOptions`. |
| `removeFocus()` | `Promise<void>` | Blur the control. |
| `checkValidity()` | `Promise<boolean>` | Delegate to inner button; true for links. |
| `reportValidity()` | `Promise<boolean>` | Delegate validity reporting; true for links. |
| `setCustomValidity(message)` | `Promise<void>` | Set a validation message; ignored for links. |

Validity methods operate on the inner control, not every field in the surrounding form. Use the form's validation API to validate the whole form.

### Slots and styling

| Slot | Content |
| --- | --- |
| Default | Button label. |
| `prefix` | Presentational content before the label. |
| `suffix` | Presentational content after the label. |

The component exposes `base`, `prefix`, `label`, `suffix`, `caret`, and `spinner` CSS parts.

```css
/* Scope a customization to buttons with this class. */
c-button.brand-action::part(base) {
  border-radius: 10px;
  font-weight: 600;
}
```
